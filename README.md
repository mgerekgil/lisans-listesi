# Lisans listesi

Motto POS ve Esnafım programlarının uzaktan lisans denetimi için **imzalı** listeler.
Listelerde kişisel bilgi yoktur (yalnızca bilgisayar kodunun özeti, durum ve bitiş tarihi).
`kayitlar.enc` ve `anahtar.enc` satıcının şifresiyle şifrelidir.

Bu depo **Lisans Yöneticisi** programıyla yönetilir; dosyaları elle değiştirmeyin.
